# Data dictionary

The warehouse uses one consultation fact table and three reference tables. Names are retained for compatibility with the existing Power BI report.

## `Patients`

| Column | Meaning | Quality rule |
|---|---|---|
| `Patient ID` | Surrogate patient identifier | Primary key, generated by SQL Server |
| `FIRSTNAME` / `LASTNAME` | Synthetic patient name | Required |
| `EMAIL` | Synthetic contact value | Required and unique |
| `CITY` / `State` | Synthetic location | Required |
| `Age` | Age in years | 0–120 |
| `Weight` | Weight in kilograms | Greater than 0 |

## `Staff_Table`

| Column | Meaning |
|---|---|
| `Staff id` | Surrogate staff identifier |
| `First Name` / `Last name` | Synthetic staff name |
| `Job Id` | Numeric role category |

## `Disease_Table`

| Column | Meaning |
|---|---|
| `Disease id` | Surrogate disease identifier |
| `DISEASE NAME` | Disease category |
| `PATHOGEN` | Pathogen category |
| `SEVERITY` | Low, Moderate or Critical |

## `Consultations`

| Column | Meaning | Quality rule |
|---|---|---|
| `consultations id` | Consultation identifier | Primary key |
| `Patient id` | Patient foreign key | Must match `Patients` |
| `Staff id` | Staff foreign key | Must match `Staff_Table` |
| `DISEASE ID` | Disease foreign key | Must match `Disease_Table` |
| `ADMISSION DATE` | Admission date | Required |
| `Discharge Date` | Discharge date | On or after admission |
| `Total cost` | Synthetic consultation cost in naira | Greater than or equal to zero |

## Derived metrics

- **Consultation count:** `COUNT(*)` from `Consultations`.
- **Total revenue / cost:** `SUM([Total cost])`.
- **Average stay:** average date difference between admission and discharge.
- **Average age by severity:** average patient age after joining consultations to patients and diseases.
